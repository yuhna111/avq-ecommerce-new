# vp/generated-java/ — Mã khung Java do VP sinh

**Chứa gì:** mã khung (skeleton) các lớp Java do Visual Paradigm **Instant Generator** sinh ra từ sơ đồ lớp.

**Ai đặt file vào:** Tôi (tác giả tiểu luận) chạy Instant Generator và chép kết quả vào. Claude Code chỉ dùng làm tham chiếu khi xây dựng `backend/`.

**Quy tắc:** ⚠️ **KHÔNG SỬA TAY**. Đây là đầu vào gốc để đối chiếu với mô hình. Nếu cần thay đổi, sửa sơ đồ lớp trong VP rồi sinh lại. Mã chạy thật được viết trong `backend/`, không viết ở đây.
