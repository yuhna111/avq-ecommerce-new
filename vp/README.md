# vp/ — Mô hình Visual Paradigm

**Chứa gì:** file dự án Visual Paradigm `AVQ_Clothing.vpp`, file xuất mô hình `model.xml`, và thư mục `generated-java/` (mã khung Java do VP sinh).

**Ai đặt file vào:** Tôi (tác giả tiểu luận) chép các file từ Visual Paradigm vào. Claude Code chỉ đọc, không tạo hay ghi đè file ở đây.

**Quy tắc:** ⚠️ **KHÔNG SỬA TAY** các file trong thư mục này. Mọi thay đổi phải thực hiện trong Visual Paradigm rồi xuất/sinh lại và chép đè vào.
