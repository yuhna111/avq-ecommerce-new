# docs/diagrams/ — Ảnh sơ đồ

**Chứa gì:** ảnh PNG các sơ đồ xuất từ Visual Paradigm (use case, hoạt động, lớp, tuần tự, ERD, …).

**Ai đặt file vào:** Tôi (tác giả tiểu luận) xuất ảnh từ VP và chép vào. Claude Code không tạo hay sửa ảnh ở đây.

**Quy tắc:** Ảnh là bản xuất từ mô hình VP — không chỉnh sửa trực tiếp; khi sơ đồ thay đổi thì xuất lại từ VP. Nguồn gốc mô hình nằm trong `vp/` (không sửa tay).
