# docs/ — Tài liệu phân tích thiết kế

**Chứa gì:**
- `business-rules.md` — quy tắc nghiệp vụ BR01–BR17 và bảng quyết định DT-01…DT-05.
- `design-notes.md` — phân bổ trách nhiệm khi thiết kế, các thay đổi CSDL DB-R1…DB-R7.
- `diagrams/` — ảnh PNG các sơ đồ xuất từ Visual Paradigm.

**Ai đặt file vào:** Tôi (tác giả tiểu luận) viết nội dung các file tài liệu và chép ảnh sơ đồ. Claude Code đọc các tài liệu này làm căn cứ khi sinh mã, chỉ chỉnh sửa khi được yêu cầu.

**Quy tắc:** Tài liệu ở đây được sửa tay bình thường. Riêng các file đầu vào trong `vp/` và `db/` thì **không sửa tay**.
